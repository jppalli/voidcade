# Message to send with the art kit

Copy, change the batch, and send it together with `needle-art-kit.zip` (made with `npm run art:kit`).

---

**Subject: Needle in a Haystack: art request, batch 1**

Hi team,

We are making *Needle in a Haystack*, a cozy hidden-object game (find the needle by brushing aside a haystack) for adults over 55 in the US. The mood is warm, nostalgic and calm. I attach a kit with everything you need:

- `ART_BRIEF.md`: the game, the look, the technical rules and the full list of pictures. **Please read sections 3 to 6 first.**
- `ART_LIST.md`: every picture with **what to draw** and the colour to use, batch by batch. Start here.
- `art-slots.csv`: the same list as a table, with the exact file name and size of every picture.
- `reference/`: what each picture looks like today, at the right size. Match the size and proportions, but redraw it in your own style. Please do not trace it.
- `incoming/`: the folders to put your finished files in (`items/`, `icons/`, `props/`). File names must be exactly as in the list.

**What I need in this batch**

1. All **13 icons** (`icons/`), as one family. SVG preferred, or PNG 128 x 128. They are delivered together, because the game switches all icons at once.
2. The **7 items of "The Sewing Box"** (`items/`), PNG 256 x 256, transparent background, thin warm brown outline, no shadow.

**Please check before sending**

- Exact file names, lower case, and the exact size in the list.
- A really transparent background, with empty space around the object (items: at least 10 px).
- No text, no frame, no drop shadow.
- Items must stand out from golden straw and still read clearly at 48 x 48 px.

I will run every file through an automatic checker and send you exactly what to fix, if anything. Files with a problem are not used, so nothing breaks while we iterate.

**Next batches (to confirm dates):** the other item sets (about 6 items each), then the scenery of each world (one world at a time).

Questions are welcome at any time. Thank you!

## What to ask for, and in what order

| Batch | What | Why this order |
|---|---|---|
| 1 | The 13 icons (one family) and one set of items ("The Sewing Box", 7) | Icons are on every screen. One set shows how the item style works in the game. |
| 2 | The other item sets, one set at a time | Each item is used the moment it arrives, and a whole set looks best in the collection book. |
| 3 | Scenery props, one world at a time (5, 4, 4, 3 and 4 pictures) | Each world is used when all of its pictures are there. |
| Later | The barn, the map backgrounds, the buttons and panels, characters | Not in the system yet. They come in the next phases. |
